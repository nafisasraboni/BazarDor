# BazarDor (বাজার দর) 🛒

BazarDor is a modern, fully responsive web application designed to track daily essential commodity prices (rice, lentils, oil, vegetables, fish, meat, etc.) across different markets, providing detailed pricing trends, market breakdowns, and price variations at a glance.

---

## 🚀 Key Features
1. **Live Price Ticker & Market Breakdown:** Features a live price marquee on the home page and detailed market-by-market comparison tables (showing minimum, maximum, and average prices across different regions like Karwan Bazar, Mirpur, etc.).
2. **Category & Sorting System:** Seamless category filtering for rice, dal, oil, and more, complete with sorting options based on price ranges.
3. **Secure Authentication:** Robust user authentication powered by BetterAuth and MongoDB, supporting Email/Password login alongside Google and GitHub social logins.
4. **Protected Routes & Toast Notifications:** Protected route mechanisms paired with smooth, customized `react-hot-toast` notifications for a seamless user experience.
5. **Modern Responsive UI/UX:** Built with Tailwind CSS and Lucide React icons, offering a clean, mobile-friendly, and elegant design.

---

## 🛠️ Technologies Used
* **Language:** JavaScript
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Authentication:** BetterAuth & MongoDB
* **Icons & Notifications:** Lucide React, React Hot Toast
* **Deployment:** Vercel
